# Instagram Исходящий Проспектинг (Outbound Prospecting)

## 1. Исследование актуального состояния API и скрейпинга (2026)

### 1.1 Официальный Instagram Graph API
* **Требования**: Доступен только для аккаунтов **Instagram Professional (Business или Creator)**, связанных с Facebook Page, прошедших верификацию приложения в Meta Developer Portal (App Review).
* **Hashtag Search API**:
  * Лимит: максимум **30 уникальных хэштегов** на один `IG User ID` за скользящее 7-дневное окно.
  * Полнотекстовый поиск по био (Bio/About) или постам **полностью отсутствует**.
  * Возвращает только `id`, `caption`, `media_type`, `permalink`, `timestamp`, `like_count`, `comments_count`. Данные владельца поста (email, телефон, подписчики) в этом методе скрыты (Privacy Protection).
* **Business Discovery API**:
  * Позволяет читать публичные данные бизнес-аккаунтов (`biography`, `followers_count`, `media_count`, последние медиа) **только по известному username**. Поиска по ключевым словам через него нет.
* **Условия Meta (Terms of Service)**:
  * Запрещают автоматический сбор персональных данных, неизбирательный скрейпинг и автоматизированную рассылку сообщений.

## 2. Постановка задачи: Исходящий поиск клиентов (Prospecting)

В отличие от бирж и Telegram-каналов, эксперты, предприниматели и блогеры в Instagram **крайне редко публикуют посты с текстом «Ищу монтажёра»**. 
Instagram в LeadHunter работает как **исходящий генератор лидов (Outbound B2B Prospecting)**:
1. Поиск целевых экспертов и бизнеса по нишевым запросам / хэштегам (например, `#недвижимостьалматы`, `#бизнесастана`, `#saasfounder`, `#podcasteurope`).
2. Оценка профиля по скоринговой модели (Relevance, Activity, Need for Video Editing).
3. Извлечение доступных публичных контактов (Telegram, WhatsApp, Email, Taplink).
4. Автоматическая генерация индивидуального первого сообщения с релевантным кейсом из `portfolioMatcher.js`.
5. **Только ручная отправка пользователем**: никаких автоматических лайков, подписок или Direct-сообщений.

## 3. Скоринговая модель профиля

1. **Размер аудитории (Audience Fit)**:
   * **3 000 – 75 000 подписчиков (Sweet Spot)**: Максимальный балл (+35). Владелец аккаунта сам принимает решения, генерирует выручку и ценит делегирование монтажа.
   * **< 2 000**: Низкий бюджет, часто монтируют сами (-15).
   * **> 150 000**: Своя продакшн-команда, сообщения в Direct не читаются владельцем (+10).
2. **Активность контента (Video Activity)**:
   * Публикует Reels / видео регулярно (> 4 в месяц): (+30).
   * Нет видео за последние 45 дней: (-25).
3. **Потенциал улучшения монтажа (Need Signals)**:
   * В био указано: «Сотрудничество», «PR», «Подкаст», «YouTube», контакты менеджера: (+20).
   * Слабая динамика, нет субтитров, базовые шрифты CapCut: (+15).
4. **Контактность (Reachability)**:
   * Наличие открытого Telegram-юзернейма / WhatsApp в био / Taplink: (+15).
   * Только Direct без ссылок: (+5).

## 5. Инструкция по подключению боевых провайдеров

### Вариант 1: Apify (Рекомендуется для промышленного поиска)
1. Зарегистрируйтесь на [apify.com](https://apify.com) и получите API Token.
2. Добавьте в `.env`:
   ```bash
   APIFY_API_TOKEN="apify_api_xxxxxxxxxxxxxxxxxxxx"
   INSTAGRAM_PROVIDER="apify"
   ```
3. Функция будет вызывать актор `apify/instagram-profile-scraper` или `apify/instagram-hashtag-scraper`.

### Вариант 2: RapidAPI Instagram Data
1. Подключитесь к любому надежному Instagram Scraper на RapidAPI.
2. Добавьте в `.env`:
   ```bash
   RAPIDAPI_KEY="xxxxxxxxxxxxxxxxxxxxxxxxxxxx"
   INSTAGRAM_PROVIDER="rapidapi"
   ```

### Вариант 3: Режим разработки и моков (по умолчанию)
* При отсутствии внешних токенов система автоматически переключается на встроенный генератор реалистичных профилей (Казахстан: Алматы/Астана, US и Европа) с полной проверкой алгоритмов скоринга, подбора портфолио и интеграции в воронку.
