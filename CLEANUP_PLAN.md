# LeadHunter UI Cleanup Plan (Minimalist / Action-Oriented)

## Цель
Радикально упростить интерфейс и удалить лишний функционал из UI и кода.
Приложение должно четко отвечать на 3 вопроса:
1. **Что нового и подходящего?** (Лента проверенных актуальных заказов)
2. **Кому написать / ответить сегодня?** (Напоминания и горячие отклики)
3. **Что в работе?** (Лиды и статус проектов монтажа)

Принцип: **«5 секунд»** — всё, что не помогает быстрее найти заказ, откликнуться на него или довести до оплаты, удаляется, а не прячется.

## Нужно решение (Спорные случаи)
1. **Квота YouTube**: квота API скрыта по умолчанию и отображается только на странице `/finder` жёлтым предупреждением при достижении >70% (7000 единиц). Если квота не превышена, виджет не занимает места.
2. **Диалоговые окна Фазы 3** (`RateCalculatorModal`, `ClientBriefModal`): вызываются опционально из контекстного меню карточки или карточки лида, не загромождая основной экран.
