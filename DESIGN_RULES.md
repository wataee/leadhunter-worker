# LeadHunter Design Rules

1. Новый элемент UI допускается, только если помогает найти заказ, откликнуться или довести до оплаты.
2. Один главный экран — одно главное действие.
3. Нет постоянных служебных статусов: показываем индикатор только при реальной проблеме.
4. Один счётчик = один понятный смысл (без дублирующих цифр).
5. Не дублировать одну и ту же функцию в двух разных местах.
6. Принцип минимализма: без горячих клавиш, пресетов и геймификации.
7. Любая новая функция добавляется только с указанием, какую существующую функцию она заменяет.
