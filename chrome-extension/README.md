# LeadHunter Copilot for Upwork (.fleur)

Chrome-расширение (Manifest V3), которое работает прямо поверх открытых страниц Upwork без скрейпинга и риска бана:

1. Откройте в Chrome `chrome://extensions/`.
2. Включите **Режим разработчика (Developer mode)** справа сверху.
3. Нажмите **Загрузить распакованное расширение (Load unpacked)** и выберите папку `chrome-extension`.
4. Откройте любой заказ на Upwork (`https://www.upwork.com/jobs/...`), нажмите на иконку расширения (или кнопку `⚡ LeadHunter Copilot` внизу справа) и в настройках при желании укажите ваш `WEBHOOK_SECRET`, чтобы заказы и переводы сразу синхронизировались с LeadHunter.
