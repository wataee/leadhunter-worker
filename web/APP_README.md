# LeadHunter — Охотник за клиентами для видеомонтажёра

**LeadHunter** — это веб-приложение, созданное специально для видеомонтажёров и контент-криейторов. Оно автоматизирует поиск платёжеспособных клиентов на YouTube, мониторит горячие вакансии «ищу монтажёра» в Telegram-каналах, ведёт воронку клиентов с авто-напоминаниями о повторных касаниях (follow-up) и готовит персонализированные холодные питчи с разбором таймкодов.

Приложение полностью статическое на фронтенде с serverless-функциями на Netlify, без сторонних серверов, Telethon и внешних баз данных. Все данные конфиденциально хранятся в вашем браузере (`localStorage` / `IndexedDB`).

## 🚀 Основные возможности

1. **Lead Finder (YouTube)**:
   - Поиск каналов в целевых нишах (недвижимость, AI-автоматизация, крипта, бизнес, фитнес, инфобизнес).
   - Фильтрация по подписчикам (по умолчанию 5k–50k), активности (ролик за последние 30 дней) и языку/региону.
   - Извлечение контактов: Telegram, Email, Instagram, сайты (taplink, tilda, getcourse).
   - Определение продукта/оффера и автоматический расчёт **Lead Score (0–100)** и тиров (Тир 1 «Кит», Тир 2 «Целевой», Тир 3).
   - **ИИ-квалификация (AI Lead Scoring)**: автоматическая оценка платёжеспособности автора, выявление до 3 гипотез болей клиента, типа монетизации и генерация снайперской первой строки сообщения без лести.
   - Итоговый скор рассчитывается по формуле: `0.4 * rule_score + 0.6 * fit_score`.
   - Защита квоты YouTube API и подсчёт использованных юнитов.

2. **Монитор вакансий (Telegram)**:
   - Парсинг сообщений из публичных каналов через веб-превью (`t.me/s/username`) без необходимости логина и Telethon.
   - Фильтры по ключевым словам (включающие и исключающие «ищу работу / портфолио»).
   - Определение релевантности и метка «Горячая» (&lt;20 минут с момента публикации) с пульсирующим индикатором.
   - Звуковой сигнал (Web Audio API) и системные браузерные уведомления при появлении новых вакансий.
   - Быстрый отклик по готовому шаблону или перенос вакансии в воронку лидов в один клик.

3. **Воронка клиентов (Канбан + Таблица)**:
   - Статусы: *Новый → Написал → Ответил → Фоллоу-ап → Созвон/Пробный → Закрыт → Отказ*.
   - Drag-and-drop карточек лидов между колонками (@dnd-kit).
   - Автоматика: смена статуса на «Написал» фиксирует дату первого касания, увеличивает счётчик дневной нормы и автоматически планирует следующий фоллоу-ап через 2 дня (регламент до 4 касаний).
   - **Power Detail**: блок «Находки по ролику» с таймкодами (например, `00:35 затянутый хук`, `02:10 нет b-roll`), которые автоматически подставляются в текст питча.
   - Экспорт лидов в CSV с кодировкой UTF-8 BOM (русский язык открывается в Excel без кракозябр).

4. **Генератор питчей и Шаблоны**:
   - 6 проверенных стратегий: «Снайпер» (точечный разбор ролика), «Дробовик» (отклик на вакансию), «Огнемёт» (предложение идеи / готовый ре-эдит), Фоллоу-ап 1 и Фоллоу-ап 2.
   - Подстановка переменных: `{имя}`, `{канал}`, `{тема_ролика}`, `{таймкод}`, `{проблема}`, `{ссылка_портфолио}`, `{ссылка_сэмпла}`, `{моё_имя}`, `{моя_специализация}`.
   - Индикаторы качества: длина (до 450 знаков), проверка на клише «услуги монтажа», наличие вопроса в конце, проверка превью в Telegram.
   - Опциональный AI-рерайтер через Anthropic Claude.
   - Кнопки «Копировать» и «Открыть в Telegram» (отправка всегда выполняется вручную пользователем!).

5. **Дашборд и Горячие клавиши**:
   - Дневная норма отправки питчей (прогресс-кольцо).
   - Конверсия в ответ и график отправки за 14 дней.
   - Список просроченных и сегодняшних фоллоу-апов.
   - Навигация по клавишам как в Linear: `g d` (дашборд), `g f` (finder), `g v` (вакансии), `g l` (воронка), `/` (поиск), `?` (список хоткеев).

## 🛠 Стек технологий

- **Фронтенд**: React 18, TypeScript, Vite, Tailwind CSS (тёмная палитра `#0D0E12`, `#14161C`, `#8B7CFF`).
- **Стейт**: Zustand с persist middleware в `localStorage`.
- **Drag-and-Drop**: `@dnd-kit/core`.
- **Иконки и Графика**: `lucide-react`, `recharts`.
- **Netlify Functions**: TypeScript, Node 18+, нативный `fetch`, парсинг HTML через `cheerio`.
- **Шрифты**: Inter и JetBrains Mono.

## 📋 Как получить API-ключи

### 1. YouTube Data API v3 (для Lead Finder)
1. Откройте [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте новый проект (например, `LeadHunter-Client`).
3. В боковом меню перейдите в **APIs & Services → Enabled APIs & Services** и нажмите **+ ENABLE APIS AND SERVICES**.
4. Найдите **YouTube Data API v3** и нажмите **Enable**.
5. Перейдите в **APIs & Services → Credentials** и нажмите **+ CREATE CREDENTIALS → API key**.
6. Скопируйте полученный ключ. Рекомендуется нажать **Edit API key** и ограничить его использование только библиотекой *YouTube Data API v3*.
7. Бесплатная квота Google по умолчанию: **10 000 юнитов в сутки** (хватает на сотни поисков).

### 2. Telegram Bot Token & Chat ID (Опционально — для дублирования вакансий в Telegram)
1. В Telegram найдите официального бота [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Следуйте инструкциям и скопируйте выданный токен бота (например, `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).
3. Чтобы узнать свой Chat ID, напишите боту [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш цифровой `Id` (например, `987654321`).
4. Нажмите `/start` в диалоге с вашим созданным ботом, чтобы разрешить ему отправлять вам сообщения.

### 3. AI-провайдеры (для ИИ-квалификации лидов и генерации питчей)
Система использует автоматическую цепочку резервирования (fallback pipeline):
1. **Google Gemini** (Основной, бесплатный):
   - Зарегистрируйтесь на [Google AI Studio](https://aistudio.google.com/).
   - Нажмите **Get API Key** и скопируйте ключ в `GEMINI_API_KEY`.
   - Модель по умолчанию: `gemini-3.8-flash` (настраивается в `GEMINI_MODEL`).
2. **Groq Cloud** (Резервный 1, сверхбыстрый и бесплатный):
   - Зарегистрируйтесь на [console.groq.com](https://console.groq.com/).
   - В разделе **API Keys** создайте ключ и скопируйте в `GROQ_API_KEY`.
   - Модель по умолчанию: `llama-3.3-70b-versatile` (настраивается в `GROQ_MODEL`).
3. **OpenRouter** (Резервный 2, бесплатные модели `:free`):
   - Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai/).
   - Создайте ключ и укажите `OPENROUTER_API_KEY`.
   - Модель по умолчанию: `meta-llama/llama-3.3-70b-instruct:free`.

### 4. Anthropic API Key (Опционально — для кнопки «Улучшить через ИИ» в модальном окне)
1. Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com/).
2. В разделе **API Keys** создайте новый ключ `ANTHROPIC_API_KEY`.

## 💻 Локальный запуск

### Вариант А: Быстрый запуск фронтенда с демо-данными
Если вы хотите просто посмотреть интерфейс без API-ключей:
```bash
# Перейдите в папку проекта
cd leadhunter

# Установите зависимости (если еще не установлены)
npm install

# Запустите локальный сервер разработки
npm run dev
```
Откройте браузер по адресу `http://localhost:5173`. Нажмите кнопку **«Загрузить демо-данные»** в сайдбаре или на дашборде.

### Вариант Б: Полный запуск с Netlify Functions
Для локальной работы серверных функций (`/api/*`):
```bash
# Установите Netlify CLI глобально (один раз)
npm install -g netlify-cli

# Создайте файл .env на основе .env.example
cp .env.example .env
# Заполните ваши ключи в .env:
# YOUTUBE_API_KEY=AIzaSy...
# TELEGRAM_BOT_TOKEN=...
# TELEGRAM_CHAT_ID=...
# ANTHROPIC_API_KEY=...

# Запустите с эмуляцией Netlify Functions:
netlify dev
```
Сервер запустится на `http://localhost:8888` с автоматическим проксированием функций.

## 🚢 Деплой на Netlify без доработок

### Способ 1: Через GitHub / GitLab (Рекомендуемый)
1. Загрузите код репозитория `leadhunter` в ваш GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit LeadHunter"
   git remote add origin https://github.com/ВАШ_АККАУНТ/leadhunter.git
   git push -u origin main
   ```
2. Зайдите на [Netlify](https://app.netlify.com/) и нажмите **Add new site → Import an existing project**.
3. Выберите GitHub и ваш репозиторий `leadhunter`.
4. Настройки сборки подтянутся автоматически из файла `netlify.toml`:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
   - **Functions directory:** `netlify/functions`
5. В разделе **Environment variables** добавьте переменные:
   - `YOUTUBE_API_KEY` = *ваш ключ YouTube*
   - `TELEGRAM_BOT_TOKEN` = *токен бота (опционально)*
   - `TELEGRAM_CHAT_ID` = *ваш chat id (опционально)*
   - `ANTHROPIC_API_KEY` = *ключ Claude (опционально)*
   - `ANTHROPIC_MODEL` = `claude-3-5-sonnet-20241022` (опционально)
6. Нажмите **Deploy Site**. Через 1–2 минуты сайт готов!

### Способ 2: Прямой деплой через Netlify CLI (в 1 команду)
```bash
# 1. Соберите проект
npm run build

# 2. Авторизуйтесь в Netlify и задеплойте
npx netlify deploy --prod
```

## ⚠️ Важные особенности и ограничения

1. **Ручная отправка**: LeadHunter **никогда не спамит автоматически**. Он готовит тексты, считает статистику и напоминает о касаниях. Финальную отправку делает человек в Telegram или на почту.
2. **Мониторинг Telegram**: Приложение работает в serverless-модели Netlify без постоянного демона. Проверка новых вакансий происходит **пока вкладка открыта в браузере** с выбранным интервалом (1, 2 или 5 минут).
3. **Публичные Telegram-каналы**: Мониторятся каналы, у которых включён веб-просмотр (страница доступна по `https://t.me/s/channel_name`). Закрытые чаты и каналы с отключённым превью не поддерживаются.
4. **Квоты YouTube Data API**: Стандартная бесплатная квота составляет 10 000 юнитов в день. Один поиск потребляет 100 юнитов, чтение деталей канала и плейлиста — по 1 юниту. В интерфейсе есть индикатор расхода квоты.
5. **Сохранность данных**: Ваши данные хранятся в браузере. Перед очисткой кэша или смене компьютера используйте кнопку **«Экспорт полного JSON»** в Настройках.
