# LeadHunter Web — Клиентское приложение для видеомонтажёров

**LeadHunter** — веб-приложение, созданное специально для видеомонтажёров и контент-криейторов. Оно автоматизирует поиск платёжеспособных клиентов на YouTube, мониторит горячие вакансии «ищу монтажёра» в Telegram-каналах, ведёт воронку клиентов и готовит персонализированные питчи.

Приложение построено на React 18 + TypeScript + Vite + Tailwind CSS + Zustand с Netlify Functions.

---

## 🚀 Основные модули

1. **Монитор вакансий (/vacancies)**:
   - Мониторинг Telegram-вакансий в реальном времени с поддержкой 152 проверенных каналов.
   - Двухуровневая фильтрация: жесткие стоп-слова соискателей/курсов и мягкие маркеры соискателей при наличии явных сигналов найма.
   - Определение релевантности, бюджета и горячих вакансий (<20 минут с момента публикации).
   - Перенос вакансии в воронку лидов в один клик с защитой от дублирования.

2. **Lead Finder (/finder)**:
   - Поиск каналов в целевых нишах YouTube (бизнес, фитнес, крипта, недвижимость, инфобизнес).
   - Фильтрация по подписчикам и недавней активности.
   - Извлечение контактов (Telegram, Email, Instagram, сайты).
   - Оценка платёжеспособности автора и гипотез потребностей в монтаже.

3. **Воронка клиентов (/leads)**:
   - Канбан-доска и табличное представление: *Новый → Написал → Ответил → Фоллоу-ап → Пробный/Созвон → Закрыт → Отказ*.
   - Автоматический приём лидов из Telegram-бота по кнопке «📥 В воронку».
   - Экспорт в CSV с поддержкой русского языка в Excel.

4. **Шаблоны и генератор питчей (/templates)**:
   - Проверенные стратегии холодных откликов.
   - Подстановка переменных: имя, канал, тема ролика, портфолио.
   - Быстрый переход в Telegram для отправки сообщения вручную.

## ⚙️ Переменные окружения Netlify

| Переменная | Обязательна | Назначение |
|---|:---:|---|
| `APP_PASSWORD` | Да (prod) | Пароль администратора для входа в веб-приложение |
| `APP_SESSION_SECRET` | Рекомендуется | Секрет подписи cookie (мин. 32 символа, либо деривируется из пароля) |
| `WEBHOOK_SECRET` | Да | Секрет авторизации запросов от воркера и callback Telegram |
| `TELEGRAM_BOT_TOKEN` | Для бота | Токен бота для отправки уведомлений и обработки кнопок |
| `TELEGRAM_CHAT_ID` | Для бота | Telegram Chat ID пользователя для приёма уведомлений |
| `UPSTASH_REDIS_REST_URL`| Для воронки | REST URL базы данных Upstash Redis |
| `UPSTASH_REDIS_REST_TOKEN`| Для воронки| REST токен Upstash Redis |
| `TG_WORKER_URL` | Опционально | URL воркера на Render для отображения статуса |
| `YOUTUBE_API_KEY` | Опционально | Ключ YouTube Data API v3 для Lead Finder |
| `GEMINI_API_KEY` | Опционально | Ключ Google AI Studio для AI-генератора |
| `GROQ_API_KEY` | Опционально | Резервный AI-ключ Groq |
| `OPENROUTER_API_KEY` | Опционально | Резервный AI-ключ OpenRouter |
| `ANTHROPIC_API_KEY` | Опционально | Резервный AI-ключ Anthropic |
